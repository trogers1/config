---
name: commit-message
description: >-
  Instructions to write a commit message.
disable-model-invocation: true
---

Write a concise-but-comprehensive commit message to `<project-root>/commit.md` that includes a title and a body. 

Prefer bullet points over long paragraphs. Do not break up long lines into multi-lines (it will become misformatted when copied).

Assume that you are writing for all non-committed changes unless otherwise instructed to just consider staged/unstaged.

Make sure to match the style of previous commits (if you are able to view them).
